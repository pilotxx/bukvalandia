# Букваландия — русский язык и математика для 2–3 класса

Обучающая игра с общим питомцем, магазином, медалями, недельными испытаниями и реальными призами от родителей.

- **📖 Русский язык (Букваландия)** — 8 миров, 33 темы, 8 боссов (программа «Школа России»).
- **🔢 Математика (Числоград)** — 9 миров, 31 тема, 9 боссов и тренажёр таблицы умножения.
  Методика: наглядные модели (брусочки-десятки, рамка десяти, группы предметов, схемы к задачам,
  часы, клетчатые фигуры) и стратегии устного счёта. Ответ вводится с клавиатуры, поэтому его нельзя угадать.
  Внутри урока примеры идут от простых к сложным, а после 2 звёзд становятся сложнее.

Новый предмет добавляется в файле `js/subjects.js`.

## Как установить на Android (планшет или телефон)

Чтобы программа устанавливалась как приложение и работала без интернета, её нужно один раз
выложить в интернет по адресу с `https://`. Просто скопировать файл на планшет не получится:
Chrome на Android не устанавливает приложения из локальных файлов.

### Вариант 1 — GitHub Pages (бесплатно, навсегда)
1. Зарегистрируйтесь на https://github.com.
2. Нажмите **New repository**, назовите его, например, `bukva`, и выберите **Public**.
3. Нажмите **uploading an existing file** и перетащите **всё содержимое** папки `bukvalandia`
   (файл `index.html`, папки `css`, `js`, `icons` и т. д.). Нажмите **Commit changes**.
4. Откройте **Settings → Pages**, в разделе *Branch* выберите `main` и `/ (root)`, затем нажмите **Save**.
5. Через 1–2 минуты появится адрес вида `https://ваше-имя.github.io/bukva/`.

### Установка на планшет
1. Откройте этот адрес в **Chrome** на планшете.
2. Нажмите меню **⋮**, затем **«Установить приложение»** (или **«Добавить на главный экран»**).
3. На рабочем столе появится иконка «Букваландия». Дальше приложение работает **без интернета**.

## Где хранится прогресс
- Только на самом устройстве, в памяти браузера. На сайт ничего не отправляется.
- Если очистить данные Chrome или удалить приложение, прогресс пропадёт.
  Поэтому раз в неделю делайте копию: **⚙️ → PIN → 💾 Сохранение → «Сохранить прогресс в файл»**.
  Файл сохранится в «Загрузки». Восстановить его можно там же, кнопкой «Загрузить прогресс из файла».
- Программа сама напомнит о копии, если её давно не было.

## Для взрослых (⚙️ в правом верхнем углу)
- **Успехи:** время занятий за неделю, точность, слабые темы, частые ошибки.
- **Призы:** свои реальные награды и их цена в монетах; подтверждение выдачи.
- **Настройки:** дневной лимит монет, напоминание о перерыве, звук, озвучка, «открыть все темы».
- Забыли PIN? Нажмите «Забыли PIN?» и решите пример для взрослых.

## Как устроена мотивация
- **Монеты** — за правильные ответы. Серия ответов подряд даёт ×1,5 и ×2, подсказка снижает награду.
  Дневной лимит (по умолчанию 700) защищает от «залипания».
- **Свежесть темы** (мягкая защита от повторов ради монет):
  - пока тема изучается (0–1 звезда), награда всегда полная;
  - с 2 звёзд: 1-й раз за день — 100%, 2-й — 60%, 3-й — 30%, дальше — 10%; на следующий день восстанавливается;
  - освоенная тема (3 звезды) даёт 50%, но через 7 дней на ней появляется 🔁 «Пора повторить» с полной наградой;
  - на карте значок 💤 означает «тема отдыхает», а в карточке темы есть кнопка «Лучше попробуй…».
- **Работа над ошибками** — ошибки можно исправить на следующий день (так лучше запоминается), по 8 монет за ошибку.
- **Учёный день** — бонус за уроки по всем предметам в один день.
- **Звёзды** (до 3 за урок) — только за точность: 3 звезды = 9 из 10 без ошибок и подсказок.
  От звёзд растёт питомец (5 стадий), а 2 звезды во всех темах мира открывают битву с боссом.
- **Уровни:** каждый следующий требует больше опыта. Новые товары открываются по уровням, цены растут.
- **Ошибки** сохраняются и возвращаются в уроки и в «Работу над ошибками» (интервальное повторение).
- **Испытания недели** — 3 задания; за все три выдаётся редкий предмет, которого нет в магазине.

## Обновление
1. В хранилище на GitHub нажмите **Add file → Upload files**.
2. Перетащите **всё содержимое** папки `bukvalandia` целиком (Ctrl+A → перетащить), вместе с папками.
   Файлы с теми же путями заменятся, а новые добавятся.
   ⚠️ Если перетащить отдельные файлы из папки `js`, они попадут не в `js/`, а в корень хранилища.
3. Нажмите **Commit changes**. Планшет обновится сам в течение 10–15 минут, при следующем запуске с интернетом.
4. Если вы добавляли новые файлы, впишите их в `FILES` в `sw.js` и увеличьте версию (`bukvalandia-v2` → `v3`).

Прогресс ребёнка при обновлении сохраняется.
