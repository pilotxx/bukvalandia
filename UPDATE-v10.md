# Букваландия: Дом приключений (версия 10)

Обновление добавляет две комнаты, занятия с питомцем, сюжетные задания и новые возможности в боях. Приложение остаётся обычной PWA без сервера и регистрации.

## Что нового

- **Три комнаты:** гостиная, мастерская после первой победы над боссом и обсерватория после третьей. Все прежние подарки остаются в гостиной на своих местах.
- **Обустроить:** перетаскивание пальцем и коробка для хранения; подарки можно переносить между открытыми комнатами через «Мои вещи». Координаты каждой комнаты сохраняются отдельно.
- **Занятия открываются за первые победы в любом предмете:** конструктор (1), рисование (2), созвездия (3), музыка (4), зеркальное рисование (5), аквариум (6), театр историй (8). После 12 побед появляются дополнительные обитатели аквариума, после 18 — маршруты на вычитание, после 25 — домашний фестиваль. Повторная победа над тем же боссом не увеличивает счётчик. Старые победы учитываются автоматически.
- **Школа питомца:** три трюка с последовательностями сигналов; три тренировки закрепляют трюк.
- **Альбом:** сохраняет названия и даты открытий, выступлений и приключений. Постройка, рисунок, мелодия и аквариум сохраняются в соответствующих занятиях.
- **Шесть приключений по восьми заданиям:** письма и словесный сыщик, кафе и архитектор, рюкзак и английская вечеринка. В заданиях появились выбор нескольких ответов, поиск причин ошибок, несколько способов решения, восстановление последовательности. Успешное прохождение (минимум 5 из 8 с первой попытки, подсказки разрешены) даёт предмет для дома. Ошибочное задание повторяется с теми же параметрами.
- **Боссы:** три этапа, тематическая загадка для каждого из 25 миров и управляемая энергия питомца. Щит защищает от одной ошибки, совет даёт подсказку, усиление добавляет урон следующему верному ответу. Варианты ответов остаются на месте во время чтения.
- **Призы:** кнопка получения за монеты кошелька сразу списывает цену; получение из копилки списывает накопленные в ней монеты. Подтверждение показывает цену, остаток и отдельной строкой бонусы достижений. Заказ нельзя обработать или вернуть дважды; повторное подтверждение не списывает цену снова.

## Как обновить с сохранением прогресса

1. На планшете в старой версии откройте **⚙️ → Сохранение → Сохранить прогресс в файл**. Это дополнительная копия на случай ошибки при загрузке файлов.
2. Обновите содержимое **того же репозитория и той же папки GitHub Pages**. Выложите файлы из архива, включая `index.html`, `sw.js`, папки `js`, `css`, `icons` и `voice`. В архиве файлы лежат в корне: дополнительную вложенную папку создавать не нужно.
3. Дождитесь завершения публикации GitHub Pages, откройте приложение на планшете с интернетом и перезапустите его. В разделе питомца появятся вкладки трёх комнат.
4. Устанавливать приложение заново и очищать данные браузера не требуется. Затем обновление работает без интернета; голосовые пакеты кэшируются после их загрузки с сетью.

Прогресс остаётся под прежним ключом `bukvalandia_v1` в локальном хранилище браузера. Версия структуры данных меняется с 5 на 6. Монеты, звёзды, питомец, предметы, PIN, заявки на реальные призы и старые координаты сохраняются. Новые поля добавляются поверх существующих данных. При первом переходе со старой версии исходное сохранение дополнительно записывается под ключом `bukvalandia_v1_before_v6`; его можно скачать через **⚙️ → Сохранение → Скачать копию до большого обновления**. Эта копия не перезаписывается при следующем запуске.

**Прежний адрес и тот же браузер/профиль важны:** локальные данные принадлежат адресу сайта. Если перенести приложение на другой адрес или другое устройство, используйте экспорт и импорт файла прогресса. Сам архив не содержит прогресса ребёнка с планшета.

## Проверка разработчиком

```sh
python -m unittest discover -s tests -v
```

Нужны Playwright для Python и Chromium. Путь браузера по умолчанию `/usr/bin/chromium`, можно задать переменную `CHROMIUM_PATH`. Тесты поднимают локальный HTTP-сервер и работают с искусственными сохранениями в изолированных профилях браузера.

Проверяются перенос сохранения версии 5 и неизменность исходной копии; списание из кошелька и копилки, отмена, недостаток средств, повторная обработка и возврат; перенос и перетаскивание предметов; прохождение всех шести приключений; фазы и способности в бою; победа над первым боссом; поздние открытия; сохранение творчества; портретная и горизонтальная ориентация планшета; офлайн-перезапуск.
